# Skills

Optional Codex-compatible wrappers for the CLI core.

Each skill lives in its own folder with a `SKILL.md` entrypoint:

```text
skills/
  memory-extractor/
    SKILL.md
  memory-verifier/
    SKILL.md
  memory-writer/
    SKILL.md
  memory-context-builder/
    SKILL.md
  memory-rubric-scorer/
    SKILL.md
  memory-cleaner/
    SKILL.md
```

Add `references/` or `scripts/` only when a skill needs bundled material.
