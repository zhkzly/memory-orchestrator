# Memory Orchestrator 简历项目表述 v1

> 版本说明：本文件只使用当前仓库与已归档实验能够核验的事实。后续版本新增效果数据时另建 v2，不覆盖本版。

## 项目名称

**Memory Orchestrator：面向 LLM Agent 的证据驱动经验记忆与 Skill 演化框架**

- 技术栈：Python、OpenAI SDK、JSON Schema、SQLite、不可变快照、外部可执行评测
- 项目链接：<https://github.com/zhkzly/memory-orchestrator/tree/codex/vault-controller-maintenance>

## 一句话定义

针对 Agent 完成任务后轨迹和反馈被丢弃、原始日志冗长且经验容易错误泛化的问题，构建“轨迹分层 → 证据提取 → 经验/Skill 候选 → 冻结对照 → 发布/回退”的长期记忆演化闭环。

## 平台／Agent 应用岗版本

**Memory Orchestrator｜Agent 经验记忆与 Skill 演化框架**

- 设计 Python 记忆演化核心，将百级事件长轨迹按用户要求、Agent 行动、工具返回和外部反馈分层，结合调用组、局部摘要、按需补读与累计 Token 预算，把原始日志转为可追溯的结构化经验。
- 实现 Experience/Skill 分层记忆、任务级检索、依赖与冲突处理、不可变候选快照、外部评分、版本选择及原子发布/回退；候选未通过质量或回归门时保持当前版本，避免错误经验直接污染后续任务。
- 针对真实实验中“通用 checklist 被注入不适用任务”的问题，引入 artifact-feedback 证据绑定和机器化 `require_any/exclude_any` 适用边界；完成 **383 项回归**及 **22 次故障注入检查**。

## 算法／研究岗版本

**Memory Orchestrator｜Evidence-Grounded Self-Evolving Agent Memory**

- 将 Agent 记忆演化形式化为 `Episode → Evidence → Experience → Skill Candidate → Validation → Release`，区分 working memory、情景经验、程序性 Skill 与模型参数，支持单轨迹发现、跨任务归集和版本化演化。
- 设计反馈闭合的经验准入机制：任务族经验必须同时引用任务要求、完整 action/result、被评分产物及同版本外部反馈；证据不足时触发补读、降为实例经验或弃权，阻止仅凭失败分数生成泛化 Skill。
- 构建冻结 case/evaluator 的 base-candidate 对照协议；在 GDPevo 小批实验中完成 **2 个任务、4 次版本对照**，识别候选在 train_001 **5/17→5/17** 无增益、train_004 **12/17→10/17** 回归并自动拒绝发布，进一步定位为规则缺失与适用范围失效，而非将负结果包装为提升。

## 推荐放入一页简历的三条

- 构建面向 LLM Agent 的经验记忆与 Skill 演化框架，将长任务轨迹和外部反馈转为可追溯经验，支持检索复用、候选生成、不可变版本及原子发布/回退。
- 设计 evidence-grounded 准入：任务族经验必须闭合任务、action/result、最终产物和反馈；结合机器化 Skill 适用边界，避免通用 checklist 跨任务误注入。
- 建立冻结评分与回归门，在 GDPevo 2 任务/4 对照实验中拦截 0 增益且发生 **12/17→10/17** 回归的候选；完成 **383 项回归测试、22 次故障注入**。

## 30 秒面试介绍

很多 Agent 做完任务后会丢掉轨迹，直接保存完整日志又太长、噪声太多；如果只让 LLM 看一个失败分数总结经验，又容易产生“以后仔细检查”这类无效 Skill。这个项目把轨迹按任务、行动、工具结果和反馈分层，只允许有完整证据链的经验进入任务族 Skill，再用冻结的旧版/候选版对照决定是否发布。真实小批实验没有得到提升，但系统成功拦截了一个无增益且造成回归的候选，并据此补上了反馈绑定和适用范围执行机制。

## 面试边界

- 当前核心通过普通 Python API 接收 Agent 轨迹和反馈；尚未完成 Codex/Claude Code 原生日志适配，不能说“已作为插件自动接入”。
- 现有实验说明闭环可以运行并拒绝坏候选，没有证明 Skill 已带来未见任务提升。
- GDPevo 当前反馈主要是字段组得分，不能定位每个订单的隐藏正确规则；系统的处理是补读或弃权，而不是从 gold 倒推规则。
- `scope.retrieval` 是显式短语匹配边界，不是完整自然语言蕴含模型；最终安全性仍由回归案例和发布门保证。

## 不建议使用的表述

- “实现了递归自我改进并显著提升 Agent 性能”
- “在 GDPevo 上取得 SOTA”
- “已无缝接入 Codex、Claude Code”
- “证明 Skill 导致了 train_004 回归”

当前证据支持的是：实现了完整演化机制，真实运行到了候选对照与拒绝；观察到候选与回归共现并定位了直接失分字段，但单次非固定随机实验不足以证明唯一因果。
