# 当前核心验收

1. [ ] 用户/项目事实按范围读写，读取无副作用，明确纠正保留来源/修订。
2. [ ] 已有经历无需 runner 即可记录；可回传已知 context 身份并追加延迟反馈。
3. [ ] 原文、事实、反馈、原因假设分开；未知不补造。
4. [ ] 有界证据、补读与弃权真实可用，引用不允许指向未读或错误项目。
5. [ ] 经验去重/检索及 task/run 计数不夸大；用户事实不被学习器改写。
6. [ ] ADD/PATCH/RETIRE/NOOP、基础版本/依赖/冲突和项目隔离受检查。
7. [ ] 候选非默认可用；评价准确绑定对象，失败保持旧版，可回退。
8. [ ] 多候选/批次是实际有限调用，未知/失败和成本不丢失或重复计数。
9. [ ] Python 直接调用样例可运行；不创建 CLI/MCP/plugin/runner 或未来兼容层。
10. [ ] 独立审查闭合，测试/实际调用/效果证据分别报告。
