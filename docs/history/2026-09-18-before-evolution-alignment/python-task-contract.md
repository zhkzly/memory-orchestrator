# Python 经验记忆实现契约
目标：按总纲实现用户/项目记忆读取、受控 Agent 执行、经验抽取/查找、Skill 更新/验证/发布的 Python 闭环。
不变量：原始记录、反馈、原因假设、候选与 active 分开；unknown 不变成成功/失败。
不变量：运行固定 Skill 快照，用户/项目记忆读取无写副作用，发布绑定确切候选与基础版本。
不变量：不预建通用插件/调度框架；保持实际调用方、全部执行与成本记录。
范围：Python 包/CLI/MCP、测试、任务样例、必要文档；对应通过后移除 TS 产品文件，保留用户数据与历史。
不做：发布远程服务、提交/推送、替用户执行外部写操作、声称未测学习提升。
金标：总纲 v1.2 的教学 schema/示例、旧 store Markdown 格式与 harness 真实构造、官方原生 CLI 公共事件文档。
授权：用户明确“按照计划来实现”、选择 Python，并表示不害怕重写；允许独立 subagent/Claude 审查。

## 追加

- 原型 TS 功能中结构评分/维护 UI 不机械迁移为真实学习能力；用户/项目记忆数据格式保留。
- 新文件先写行为验收取得真实 RED，实现首个 GREEN 后用官方 mutation_license.py 验证拒绝路径；工具要求目标文件存在且基线为绿，不能给不存在的新文件伪造预先执照。已有文件改动按可执行基线先领执照。
- 最新范围纠正：本轮只实现 Python 记忆核心，不实现 Codex/Claude 适配、CLI、MCP、插件或 Agent runner。轨迹/反馈由调用方传入；候选检查通过一个普通 evaluator 回调，没条件则保留候选。旧 TS 清理在 Python 核心验收后处理，用户数据不删。
