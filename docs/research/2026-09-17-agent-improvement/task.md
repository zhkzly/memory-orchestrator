# 研究契约
目标：为现成 Coding Agent 的改进项目建立动机、文献缺口、方法假设、可证伪实验与答辩边界。
不变量：候选缺口必须对照最接近的一手工作；多 Agent 意见不等于实验事实；不得把复现或接口封装冒充新方法。
不变量：区分文献证据、本地代码证据、待实测假设与用户尚未作出的产品选择。
范围：仅进行研究、独立质疑与本地文档；不修改运行时代码、全局 Agent 配置，不启动模型实验。
参照：SkillFlow、Evo-Harness、SkillSmith、ReasoningBank 与 OpenViking 的论文/官方实现，以及当前仓库真实接口。
痛点证据边界：本轮尚无一组独立标注的用户日常失败案例，不能把候选机制失效当作已观测事实。
交付：独立审查记录、最近邻比较、一个主候选与否决条件、可复核的论文式论证。

## 追加

- 用户纠正：需要从动机到方法连贯的项目，不能以复现某篇论文作为项目目标。
- 本轮请求已明确授权多个 Agent 质疑；采用互不提供候选结论的第一轮审查，再对候选进行交叉质疑。
- 私人项目推断仅保留本地。OpenViking 若归档，只包含公开文献事实和链接。
- 2026-09-18：GRASP、SkillEvo、SkillSV 等近邻先后否决宽泛的回归门、反馈归因和反事实估值新意；停止通过叠加条件保护选题。裁决详见 candidate-screening.md。
- 用户已明确创新要求：“独立解决真实问题，论证和实验扎实；不要求发明新算法”。后续以工程净价值为立项标准；已有方法是来源与基线，不因其存在自动否决项目。最新提案见 project-proposal.md。
