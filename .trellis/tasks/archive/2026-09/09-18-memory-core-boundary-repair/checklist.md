# 根因修复验收

1. [x] 反馈在本地源已知时正确关联run/产物/项目/修订；未知导入仍合法。
2. [x] 记录可见与可学习分开，已知本地组未闭合前无模型调用/经验写入；冻结用途继续拒绝。
3. [x] partial事件不丢失、初态已知矛盾显式可见；终态不被当成任务真值。
4. [x] call/goal/parent等已知结构改变时，实际模型可见证据随之改变；预算/引用校验仍成立。
5. [x] 同内容多提案只比较唯一快照，同时全部proposal与usage保留。
6. [x] 原始评价结果已写而Validation未写时，报告已有结果，不借此发布。
7. [x] 采样与比较、尝试与候选、模式与终态分别计量；未知和费用不被抹成0。
8. [x] shared规则的所有现有消费者同步，不新增没有消费者的抽象或字段。
9. [x] 正常导入、生成/修订、比较、选择、发布/回退与旧数据的明确边界不回归。
10. [x] HTML/任务完成度与行为证据一致，未实现/未验证/外部职责分别保留。
