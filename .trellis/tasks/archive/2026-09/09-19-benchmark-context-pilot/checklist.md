# 验收

1. [x] 官方数据/环境/评分器版本和小批清单在模型调用前冻结；许可和实际任务形状已检查。
2. [x] 实际执行使用声明模型、工具、上下文与原始可执行评分；gold不进入Actor，失败分母不丢。
3. [x] 原始model messages及各节点输入构成、预算、输出、修复和下游结果可审计。
4. [x] 至少同配置的无记忆与记忆条件；不能以不同执行器或额外隐形上下文制造提升。
5. [x] 每个问题有原始失败与第一因果偏差；提示词/上下文优先核对，不能只补代码门。
6. [x] 修复有同一实际消费者的RED/GREEN与必要官方mutation；提示词revision/hash与打包同步。
7. [x] 复测保持数据/执行/评分/预算可比，先前失败保留，探测资料不回写学习或修复。
8. [x] 报告任务/模型调用分母、正确/错误/未知、成本/耗时、上下文问题和剩余证据边界；本地提交。

终态：第7项probe按相同可部署状态停止规则记not_run，不计成功或失败；本轮完成诊断与有界复测，不宣称解决全部语义学习问题。
