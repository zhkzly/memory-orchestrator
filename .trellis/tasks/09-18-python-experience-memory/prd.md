## 职责

- 记忆系统负责计划必要采样/比较、整理证据、提出修改、汇总全结果、选择和发布版本。
- 普通 Python execute/evaluate 函数提供实际执行/评分能力及其可观察证据与限制，不要求核心先接 Codex。
- 已有经历可直接导入；缺 snapshot/context/feedback 合法，缺失影响结论，不能伪造字段。
- 用户/项目事实只按明确输入纠正；学习器不根据 reward 修改用户事实。
